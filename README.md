# Proxy Link Fixer

Юзерскрипт для прокси-серверов вида `/proxy/http://site.com/`. Исправляет ссылки и формы на странице, подставляя правильный оригинальный домен и путь вместо адреса самого прокси-сервера. Работает и с динамически подгружаемым контентом через `MutationObserver`. Установка через Tampermonkey/Violentmonkey.

## Проблема

Многие сайты используют относительные ссылки (`/search/test`, `search.php`) или абсолютные пути (`/forum/viewforum.php`). Без исправления браузер резолвит их относительно адреса прокси-сервера, а не оригинального сайта — в итоге ссылки ломаются:

http://ваш-прокси/search/test

вместо

http://ваш-прокси/proxy/http://оригинальный-сайт.com/search/test

## Что делает скрипт

- Определяет оригинальный домен и путь из текущего адреса (`/proxy/http://...`)
- Проходит по всем `<a href>` и `<form action>` на странице и подставляет в них полный правильный адрес
- Следит за динамически подгружаемым контентом (AJAX, бесконечная прокрутка и т.п.) через `MutationObserver`
- Не трогает `javascript:`, `#`, `mailto:` ссылки и уже исправленные адреса

## Установка

1. Установите расширение Tampermonkey (https://www.tampermonkey.net/) или Violentmonkey (https://violentmonkey.github.io/)
2. Создайте новый скрипт и вставьте код `Proxy Link Fixer`
3. Сохраните — скрипт сработает автоматически на любой странице с адресом вида `/proxy/http(s)://...`

## Использование

Дополнительная настройка не требуется — скрипт сам определяет прокси-сервер и оригинальный сайт из текущего URL страницы.

## Ограничения

- Рассчитан на формат прокси-URL `.../proxy/http(s)://домен/путь`. Для другого формата потребуется поправить строку `location.pathname.startsWith('/proxy/')`
- Не перехватывает клики и отправку форм — только переписывает атрибуты `href`/`action` в разметке
- Если сам прокси-сервер отдаёт "урезанный" путь оригинального сайта в адресной строке, скрипт это исправить не может — проблема на стороне сервера
