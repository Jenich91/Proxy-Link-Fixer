# Proxy-Link-Fixer
Юзерскрипт для прокси-серверов вида /proxy/http://site.com/. Исправляет ссылки и формы на странице, подставляя правильный оригинальный домен и путь вместо адреса самого прокси-сервера. Работает и с динамически подгружаемым контентом через MutationObserver. Установка через Tampermonkey/Violentmonkey.
